# Security Policy

## Supported Versions

Yess Bangla takes the security and integrity of our software, data, and users very seriously. Security patches are prioritized for all actively maintained production repositories.

| Ecosystem Service | Supported |
| :--- | :--- |
| Shondhaan Mobile (Flutter) | :white_check_mark: |
| Shondhaan Microservices Mesh | :white_check_mark: |
| Yess Soft Enterprise Platforms | :white_check_mark: |
| Yess Host Cloud Systems | :white_check_mark: |
| Organic Haat E-Commerce | :white_check_mark: |

## Reporting a Vulnerability

If you believe you have discovered a security vulnerability in any Yess Bangla application, API, mobile package, or infrastructure component:

1. **Do NOT publicly disclose the issue** via public GitHub issues, discussions, social media, or forum posts.
2. Please email a detailed report to **[info@yessbd.com](mailto:info@yessbd.com)** (or `security@yessbd.com`).
3. Include the following details in your report:
   - Affected repository, component, or URL.
   - Step-by-step reproduction instructions or a minimal Proof of Concept (PoC).
   - Potential impact of the vulnerability.
   - Any suggested mitigations or patches.

### Our Response Process
* **Acknowledgment:** We will acknowledge receipt of your report within 48 hours.
* **Assessment:** Our engineering team will assess and validate the severity and impact.
* **Remediation:** We will keep you updated as we develop, verify, and deploy a fix.
* **Credit:** We gratefully acknowledge security researchers who adhere to coordinated responsible disclosure.
