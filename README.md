# Yess Bangla Organization Configuration (`.github`)

This repository hosts global community health files, standard workflows, and the official organization profile README for **[Yess Bangla](https://github.com/Yess-Bangla)**.

## 📁 Repository Structure

```
.github/
├── profile/
│   └── README.md              # Organization Profile README displayed on https://github.com/Yess-Bangla
├── ISSUE_TEMPLATE/
│   ├── bug_report.yml         # Standardized Bug Report issue form
│   └── feature_request.yml    # Standardized Feature Request issue form
├── PULL_REQUEST_TEMPLATE.md   # Standard Pull Request template for org repositories
├── CODE_OF_CONDUCT.md         # Community Guidelines and Code of Conduct
├── SECURITY.md                # Vulnerability disclosure and security policy
└── README.md                  # This file
```
